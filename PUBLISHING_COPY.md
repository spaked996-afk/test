## Title

ClearKey — Pixel Input Prompts for Godot 4

## One-line hook

Readable keyboard, mouse, and brand-neutral gamepad prompts with dark/light themes and pressed states — ready as Godot nodes, SVG, and PNG.

## Short description

Stop wiring control hints by hand for every prototype. ClearKey gives you crisp 16×16 prompts, four PNG sizes, editable SVG, consistent file names, an InputMap/event resolver, and a `ClearKeyPrompt` node that switches theme/state from the Inspector or code.

## Long description

ClearKey is a compact input-prompt system for Godot 4 and other engines.

- 20 prompts: keyboard, mouse, and neutral gamepad positions
- dark + light themes
- normal + pressed states
- transparent PNG: 16, 32, 64, 128 px
- editable SVG source
- Godot 4 custom node and demo scene
- JSON manifest for tooling and remapping
- InputEvent/InputMap resolver with last-device preference
- no console logos, copied assets, telemetry, network calls, or runtime dependencies

The free sampler is usable in commercial projects and lets you test the workflow. The complete 92-prompt pack adds the full keyboard, function keys, navigation keys, mouse actions, and generic gamepad controls.

AI disclosure: OpenAI Codex assisted the icon design, geometry-generation code, product code, documentation, and research. Final PNG/SVG files were deterministically rendered by that code and manually inspected. No diffusion/text-to-image model or third-party art was used.
